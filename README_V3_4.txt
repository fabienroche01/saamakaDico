SAAMAKA DICO — TESTEURS 3.4

Les deux anciens exports sont remplacés par un seul bouton :

EXPORTER MA MISSION

L'export contient :
- le profil du testeur ;
- le numéro de mission ;
- le nombre de mots attribués ;
- le nombre de mots validés ;
- le nombre de corrections proposées ;
- le nombre de mots restants ;
- la liste des validations ;
- le détail complet des corrections.

Chaque testeur envoie donc un seul export à la fin de sa mission.
