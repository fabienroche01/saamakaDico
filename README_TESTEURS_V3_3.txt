SAAMAKA DICO — VERSION TESTEURS 3.3

Nouveauté principale :
les mots sont répartis automatiquement entre plusieurs testeurs.

Exemple avec 5 testeurs :
- testeur 1 : numéro 1, total 5 ;
- testeur 2 : numéro 2, total 5 ;
- testeur 3 : numéro 3, total 5 ;
- testeur 4 : numéro 4, total 5 ;
- testeur 5 : numéro 5, total 5.

Chaque testeur reçoit un lot différent.
La validation guidée ne montre que les mots de son lot.

IMPORTANT :
- tous les testeurs doivent saisir le même total ;
- chaque testeur doit avoir un numéro unique ;
- la recherche libre reste disponible sur tout le dictionnaire ;
- seules les validations guidées sont réparties.

Avec 1 313 entrées et 5 testeurs :
environ 262 ou 263 mots par personne.
