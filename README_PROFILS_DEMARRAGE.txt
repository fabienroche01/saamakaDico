SAAMAKA DICO TESTEURS 3.3.1

Au premier démarrage, l'application propose directement :
- Testeur 1
- Testeur 2
- Testeur 3

Chaque personne choisit un numéro différent.
Le choix est mémorisé sur le téléphone.
La validation guidée affiche uniquement le lot attribué à ce profil.

Répartition approximative pour 1 313 entrées :
- Testeur 1 : environ 438 mots
- Testeur 2 : environ 438 mots
- Testeur 3 : environ 437 mots

Le profil peut être changé dans l'onglet Testeurs.
