SAAMAKA DICO — VERSION TESTEURS 2.9

Cette version est volontairement figée avant l’ajout des images, de l’audio et des quiz.

FONCTIONS :
- recherche français ↔ saamaka ;
- fonctionnement hors connexion ;
- favoris ;
- historique ;
- copie et partage ;
- formulaire intégré de correction ;
- nom du correcteur mémorisé ;
- corrections enregistrées localement ;
- export groupé des corrections par Gmail, WhatsApp, Drive, etc.

UTILISATION DES CORRECTEURS :
1. Ouvrir l’onglet Testeurs et saisir son nom.
2. Rechercher un mot.
3. Ouvrir la fiche.
4. Appuyer sur Proposer une correction.
5. Modifier le français et/ou le saamaka.
6. Ajouter un commentaire si nécessaire.
7. Enregistrer.
8. À la fin, aller dans Testeurs puis Exporter toutes les corrections.

CRÉER L’APK :
Dans Android Studio :
Build > Build Bundle(s) / APK(s) > Build APK(s)

Le fichier se trouve généralement ici :
app/build/outputs/apk/debug/app-debug.apk

IMPORTANT :
Les corrections ne modifient jamais directement le dictionnaire officiel.
Elles sont enregistrées séparément pour validation par l’administratrice.
