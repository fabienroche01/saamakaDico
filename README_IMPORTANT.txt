Installation :
1. Décompresser le ZIP.
2. Dans Android Studio : File > Open.
3. Ouvrir SaamakaDico_Android_v2_8.
4. Attendre la synchronisation Gradle.
5. Sélectionner Pixel 8.
6. Cliquer sur Run.
