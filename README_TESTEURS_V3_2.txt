SAAMAKA DICO — VERSION TESTEURS 3.2

Nouveautés :
- mode de validation guidée ;
- bouton « Commencer la validation guidée » ;
- après validation, passage automatique au prochain mot non validé ;
- bouton « Passer au mot suivant » ;
- coche visible sur les résultats déjà validés ;
- export séparé des corrections et des validations ;
- progression conservée sur le téléphone.

Méthode conseillée aux testeurs :
1. Ouvrir Recherche.
2. Appuyer sur « Commencer la validation guidée ».
3. Vérifier le mot.
4. Appuyer sur « Oui, traduction correcte » ou « Non, corriger ».
5. Continuer jusqu’à la fin.
6. Dans l’onglet Testeurs, exporter les validations et les corrections.

Installation :
- ouvrir le projet dans Android Studio ;
- sélectionner le Xiaomi ;
- cliquer sur Run.
